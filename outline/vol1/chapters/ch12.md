## ch12 비트 패킷: 하이레이어의 유령 [중간점]

- **막 / 화수**: 2막 중간점 / 1권 12화 (구 ch16 + ch17 + ch18 통합 ◎)
- **POV (시점·시제)**: 이준서(ML) → 한연우(FL) 코다 · 3인칭 제한 · 과거시제
- **분량 목표**: 7,000자 내외 (중간점, 통합화)
- **로그라인**: 하이레이어로 사라지는 연우를 목격한 준서 — 그녀가 '그 위'의 사람이라는 충격 앞에, 모든 의심이 하나의 형체로 모인다.

### 1. 챕터 목적 (드라마 기능)
- **중간점(Midpoint) 폭로**: 준서가 연우의 *계급적 실체*(하이레이어 출입)를 직접 목격 → 의심이 확신으로 전환되는 분기점.
- **F7(기록 삭제 경고) plant** + **F16(익명 권력자) 강화**: 연우의 특혜가 스튜디오를 넘어선 윗선에서 온다는 암시.
- 준서가 에이단의 '안정 유도'를 결정적으로 거부(E7)해, 능동적 주체로 완성.

### 2. 시작 상태 / 끝 상태
- **시작**: "조금만 더"의 유예 속, 그러나 의심을 멈출 수 없는 준서.
- **끝**: (ML) 하이레이어 전용 구역으로 들어가는 연우를 목격 → 충격. (FL 코다) 핸들러 오의 경고 *"추락하면 모든 기록이 삭제된다"* — 연우의 공포가 정점에.

### 3. 정서 곡선
의심 5 → (추적의 긴장) 6 → (목격의 충격) 2 → (배신감·혼란) 3 / (FL) 공포 2. **1권 전체 텐션의 첫 절정.**

### 4. 씬 분해

#### scene 1 — 에이단을 끄다 (준서의 방→레이어 경계 / 낮 / 준서·에이단)
- **씬 목적**: 준서가 시스템의 '안정'을 결정적으로 거부(E7)하고 진실을 택하는 능동성.
- **진입 훅**: 에이단이 "이 추적은 CQ를 위협합니다. 중단을 강력 권장"이라 막아선다.
- **비트 전개**: 준서가 노이즈 스티커로 에이단을 *스스로* 멀리한다 → "안정되느니, 알고 싶어" → 8년차 AI의 만류를 처음으로 끊어낸다.
- **연출 지시**: 에이단 음성이 안개로 멀어진다(§11.1). 준서의 결연함.
- **호흡·페이싱**: 결단의 단문.
- **문체·보이스**: 준서=조용한 반항(체제 비판 아닌 '진실' 추구).
- **대사 톤 샘플**: (에이단) "권장: 즉시 귀가." / (준서) "오늘은, 네 말 안 들어."
- **복선/캐논**: E7(사고 퇴화 거부)·§11.1 / §8 CQ 위협.

#### scene 2 — 유령처럼, 위로 (레이어 경계 / 낮 / 준서, 연우 원경)
- **씬 목적**: 중간점 폭로. 연우=하이레이어 사람이라는 *직접 목격*.
- **진입 훅**: 멀리, 연우가 *권한 게이트를 통과해* 위로 올라간다 — 패시브는 못 가는 곳.
- **비트 전개**: 연우의 출입 목격 → 금색 스킨·거짓 주소·리아 영상이 *한 점으로* 모인다 → "연우는, 저 위의 사람이야." 의심→확신.
- **연출 지시**: 게이트의 빛 속으로 사라지는 연우의 뒷모습. 준서의 무너지는 얼굴. 슬로우.
- **호흡·페이싱**: 목격의 정적 → 깨달음의 단문 연쇄.
- **문체·보이스**: 준서의 충격을 독백으로.
- **대사 톤 샘플**: (속으로) *거짓 주소도, 금색도, 그 노래도…… 전부 여기로 이어졌어.*
- **웹소설 장치**: 중간점 클리프행어 — 준서가 처음으로 "그럼, 리아는?"이라 자문한다(진실의 문턱).
- **복선/캐논**: F1·F2·F4 수렴 / §6 계급 출입.

#### scene 3 — 삭제될 사람 (하이레이어 거처 / 같은 밤 / 연우·핸들러 오) *[FL 코다]*
- **씬 목적**: F7 plant·F16 강화. 연우가 *왜* 말 못 하는지(공포)를 독자에게 각인.
- **진입 훅**: 오가 연우에게 경고한다 — 준서의 추적이 감지됐다.
- **비트 전개**: "추락하면 모든 기록이 삭제된다. 너도, 그와의 시간도"(F7) → 특혜의 출처가 스튜디오 너머 *익명의 권력자*임이 암시(F16) → 연우의 공포: 말하면 둘 다 사라진다.
- **연출 지시**: 금빛 새장의 차가운 화려함. 오=악인 아닌 집행자(압력).
- **호흡·페이싱**: 서늘하게, 회말 여운.
- **문체·보이스**: 연우=공포를 누른 침묵.
- **대사 톤 샘플**: (오) "그를 지키고 싶으면, 모른 척해." / (연우, 속으로) *침묵만이, 그를 지킨다.*
- **웹소설 장치**: 회말 훅 — 같은 밤, 준서는 진실에 다가가고 연우는 침묵을 택한다(교차의 비극).
- **복선/캐논**: **F7 plant**(R13·R14 회수)·**F16 강화**(3권) / §9(특혜·NDA·추락).

### 5. 회말 훅 (클리프행어)
준서는 진실의 문턱에 섰고, 연우는 침묵의 자물쇠를 채웠다. 두 사람은 같은 밤, 가장 멀어진다.

### 6. 금지 사항
- 진실(감정 원본)의 *완전한 명시* 금지 — 준서는 '계급+리아 연결 의심'까지. 확정은 R13(F3).
- F16 권력자 정체(빅터) 노출 금지(3권). 오를 악인화 금지.

### 7. 사용 캐논 / 사용 금지 캐논
- 사용: §6·§9(특혜·NDA·추락)·§11.1·E7 / F7·F16.
- 금지: 빅터·생명연장·봉인 편지 직접 노출.
