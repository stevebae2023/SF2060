## ch08 비트 패킷: 금빛 흔적

- **막 / 화수**: 2막 / 1권 8화 (구 ch11)
- **POV (시점·시제)**: 이준서(ML) · 3인칭 제한 · 과거시제
- **분량 목표**: 6,000자 내외
- **로그라인**: 그라운드레이어엔 있을 수 없는 금색 — 떨어진 넥 패치 스킨 하나가, 준서의 마음에 첫 의심의 못을 박는다.

### 1. 챕터 목적 (드라마 기능)
- **F1(금색 넥 패치 스킨) payoff-도입**: 의심의 계단 본격화. 준서가 연우의 '계급적 이질감'을 처음 *물증*으로 감지.
- 하이레이어의 물리적 장벽을 세워 추적을 좌절시키고, 계급의 벽을 체감시킨다(§6).
- F8(준서의 무심한 말) plant 배치.

### 2. 시작 상태 / 끝 상태
- **시작**: 위쪽으로 사라진 연우를 쫓아 미드/스카이레이어 경계까지 온 준서.
- **끝**: 연우가 흘린 *아키텍트 전용 금색 스킨*을 줍는다. "이건…… 여기 사람 게 아니야." 첫 의심 확정.

### 3. 정서 곡선
의지 6 → (장벽 앞 좌절) 4 → (재회의 반가움) 7 → (금색 발견) 충격·의심 3.

### 4. 씬 분해

#### scene 1 — 올라갈 수 없는 곳 (레이어 경계 / 낮 / 준서·경비 시스템)
- **씬 목적**: 계급의 물리적 벽을 체험으로. 추적의 한계.
- **진입 훅**: 통로 입구의 *권한 없음* 경고. 준서의 패치 등급으론 못 올라간다.
- **비트 전개**: 경비 시스템의 차단 → 패시브에겐 닫힌 위층 → 무력감(§6 수직 계급 도시).
- **연출 지시**: 위로 뻗은 통로의 빛 ↔ 막힌 준서. 고도의 권력.
- **호흡·페이싱**: 좌절의 정적.
- **대사 톤 샘플**: (안내음) "접근 권한이 없습니다." / (준서, 속으로) *연우는, 저 위에 있는 건가.*
- **복선/캐논**: §6 계급 거주·넥패치 등급.

#### scene 2 — 우연한 재회, 그리고 (경계 카페 / 낮 / 준서·연우)
- **씬 목적**: 짧은 재회로 관계의 온기를 잠깐 회복시킨 뒤, 회말에 의심으로 뒤집기.
- **진입 훅**: 포기하고 돌아서는데, 연우가 거기 있다 — 당황한 얼굴로.
- **비트 전개**: 어색한 재회·연우의 둘러댐 → 준서의 안도 → 연우가 서둘러 떠나며 *무언가를 떨어뜨린다*.
- **연출 지시**: 연우의 불안한 눈빛(독자: 들킬까 두렵다). 준서는 반가움에 눈치 못 챔.
- **호흡·페이싱**: 따뜻하다 → 회말 급랭.
- **문체·보이스**: 연우=방어적 둘러댐(정체 직접 언급 금지). 준서=직진.
- **대사 톤 샘플**: (준서) "여기서 뭐 해요?" / (연우) "……잠깐, 볼일이." (F8 plant) (준서) "넌 계급 같은 건 신경 안 쓰는 사람 같아." — 연우의 표정이 굳는다.
- **복선/캐논**: **F8 plant**(준서의 무심한 말, 결말 회수) / §12.1 연우 보이스.

#### scene 3 — 금색 (경계 카페 앞 / 낮 / 준서, 혼자)
- **씬 목적**: F1 payoff-도입. 첫 의심 확정.
- **진입 훅**: 연우가 떠난 자리, 바닥에 *금색으로 빛나는* 작은 조각.
- **비트 전개**: 줍고 보니 **아키텍트 전용 넥 패치 스킨**(그라운드엔 없는 고가품, §6) → "이게 왜 연우한테서?" → 첫 의심의 못.
- **연출 지시**: 금색의 클로즈업, 회색 바닥과의 대비. 준서의 흔들리는 눈.
- **호흡·페이싱**: 짧은 문장으로 의심을 못 박기.
- **문체·보이스**: 준서의 혼란을 독백으로.
- **대사 톤 샘플**: (속으로) *여기 사람이…… 아닌 건가, 연우는.*
- **웹소설 장치**: 회말 클리프행어 — 금색을 손에 쥔 채, 준서가 처음으로 *그녀를 의심한다*.
- **복선/캐논**: **F1 payoff-도입**(금색 스킨=의심·추적 동기, R10~R13 단계 확신) / §6.

### 5. 회말 훅 (클리프행어)
손바닥 위의 금색. 그라운드레이어엔 없는 빛. "연우, 당신 누구야."

### 6. 금지 사항
- 금색 스킨의 의미를 *전부* 설명 금지(감정 원본·특혜는 R12에서). 여기선 '계급 이질감'까지만.
- 연우의 정체 직접 노출 금지.

### 7. 사용 캐논 / 사용 금지 캐논
- 사용: §6(계급·넥패치 등급)·§9(아키텍트급 특혜 암시) / §12.
- 금지: F3·F4·F7 / 핸들러·컨소시엄 직접 노출.
