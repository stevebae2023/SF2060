## ch11 비트 패킷: 자괴의 무게

- **막 / 화수**: 2막 / 1권 11화 (구 ch15)
- **POV (시점·시제)**: 한연우(FL) · 3인칭 제한 · 과거시제
- **분량 목표**: 6,000자 내외
- **로그라인**: 사랑이 추출되고, 그 사랑으로 사랑하는 사람을 속인다 — 연우는 두 겹의 죄책감 사이에서 이별을 결심하지만, 그의 진심 앞에 무너진다.

### 1. 챕터 목적 (드라마 기능)
- 연우의 내적 위기(자괴+기만의 죄책감)를 정점으로 끌어올려 FL 아크의 무게를 확립.
- 진우의 압박을 강화해 R13(붕괴)·R15(추락 선택)로 가는 긴장을 적재. F5(카드)·F7(기록 삭제 경고) 빌드업.
- 연우가 *떠나려다 못 떠나는* 모순으로, 독자의 안타까움(웹소설 몰입) 극대화.

### 2. 시작 상태 / 끝 상태
- **시작**: 자신의 마음이 리아로 송출되는 걸 본 직후의 연우. 죄책감의 늪.
- **끝**: 준서에게 이별을 고하려 만나지만, 그의 무구한 진심 앞에 말을 삼킨다. "조금만…… 더." — 비밀은 더 깊어진다.

### 3. 정서 곡선
자괴 3 → (진우 압박) 2 → (이별 결심) 4 → (준서의 진심에 흔들림) 6 → (말을 삼킴) 5, 먹먹.

### 4. 씬 분해

#### scene 1 — 두 겹의 죄 (연우의 거처 / 밤 / 연우, 혼자)
- **씬 목적**: 연우 자괴의 *구조*를 보여주기 — ①내 진심이 상품이 된다 ②그 상품으로 그를 속인다.
- **진입 훅**: 리아의 신작(자신의 마음)이 차트에 오른다. 팬들의 찬사가 연우에겐 칼이다.
- **비트 전개**: 추출의 고통 + 준서를 속이는 죄책감의 중첩 → "이건 사랑이 아니라 도둑질인가" → 그러나 NDA·특혜·추락 공포가 입을 막는다(§9).
- **연출 지시**: 화려한 차트 UI ↔ 연우의 무너진 표정. 금빛 새장의 차가움.
- **호흡·페이싱**: 내면 독백 위주, 느리게.
- **문체·보이스**: 연우=고급 어휘 아래 날것의 고통.
- **대사 톤 샘플**: (속으로) *그가 사랑하는 건 내 마음인데, 그는 그걸 내 것인 줄 모른다.*
- **복선/캐논**: §9(NDA·특혜·추락 공포) / §12.1.

#### scene 2 — 필요라는 압박 (스카이레이어 / 낮 / 연우·강진우) *[F5·F7 빌드업]*
- **씬 목적**: 진우의 압박을 '유혹'에서 '협박'으로 한 단계 높이고 F5·F7 빌드업.
- **진입 훅**: 진우가 '비밀 신분 보장'을 다시 꺼낸다 — 이번엔 조건과 함께.
- **비트 전개**: "내 옆에 오면 안전해. 거절하면……"(F5 카드 실체화) → 핸들러 오의 경고가 겹친다 *"추락하면 모든 기록이 삭제돼"*(F7) → 연우의 공포.
- **연출 지시**: 우아한 협박. 진우의 미소 뒤 서늘함.
- **호흡·페이싱**: 긴장 상승.
- **대사 톤 샘플**: (진우) "선택은 늘 네 거야. 결과가 정해져 있을 뿐이지." / (오) "추락하면, 넌 처음부터 없던 사람이 돼."
- **복선/캐논**: **F5·F7 빌드업**(R13·R14·R15 회수) / §8.4 추락 공포·§9.

#### scene 3 — 삼킨 이별 (그레이 브루 / 저녁 / 연우·준서)
- **씬 목적**: 이별 결심 → 진심 앞 무너짐. 비밀이 더 깊어지는 모순으로 안타까움 극대화.
- **진입 훅**: 연우가 준서를 불러낸다. "할 말이 있어요." (이별을 말하려)
- **비트 전개**: 준서의 무구한 진심("당신이 누구든 상관없어요, 나는") → 연우의 결심이 흔들림 → 결국 이별을 삼키고 "조금만 더"라 말한다.
- **연출 지시**: 말하려다 멈추는 입. 준서의 흔들림 없는 눈.
- **호흡·페이싱**: 대사의 침묵을 길게.
- **문체·보이스**: 준서=직진의 다정(F8 결과 빌드). 연우=삼킴.
- **대사 톤 샘플**: (준서) "비밀 있어도 괜찮아요. 천천히 말해줘요." / (연우) "……조금만 더, 이렇게 있어도 돼요?"
- **웹소설 장치**: 회말 훅 — 연우의 "조금만 더"가, 곧 닥칠 붕괴를 더 아프게 만든다.
- **복선/캐논**: F8 빌드(준서의 무조건적 수용) / §12.1.

### 5. 회말 훅 (클리프행어)
이별을 삼킨 한마디. "조금만 더." — 그 유예가, 두 사람을 더 깊은 벼랑으로 데려간다.

### 6. 금지 사항
- 연우가 정체를 *발설* 금지(삼킨다). 진우를 평면 악역화 금지(우아한 압박).
- F7을 과노출 금지(R13·R14에서 무게).

### 7. 사용 캐논 / 사용 금지 캐논

- 금지: 생명연장·컨소시엄·빅터.
