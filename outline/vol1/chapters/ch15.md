## ch15 비트 패킷: 금색 카드를 찢다 ― 추락

- **막 / 화수**: 3막 / 1권 15화 (구 ch25 + ch26 + ch27 통합 ◎)
- **POV (시점·시제)**: 한연우(FL) · 3인칭 제한 · 과거시제
- **분량 목표**: 7,000자 내외 (통합화)
- **로그라인**: 연우가 금색 카드를 찢는다 — 「리아」도, 금빛 새장도 버리고, 처음으로 *자기 이름으로* 추락하기를 택한다.

### 1. 챕터 목적 (드라마 기능)
- **F5(신분 보장 카드) payoff**: 기득권 vs 사랑의 선택을 *행동*으로 완성. 연우 아크의 정점.
- 「리아」 프로젝트 중단과 연우의 추락(강제 이주)을 통해 세계의 대가를 치르게 하고, R16(재회)의 무대를 그라운드레이어로 내린다.
- 준서 측의 상실감(리아 소멸)을 짧게 교차해 R16 재정의의 정서를 적재.

### 2. 시작 상태 / 끝 상태
- **시작**: 선택의 방향을 정한 연우, 핸들러 오·진우와의 대면.
- **끝**: 특혜 전면 박탈·그라운드레이어 강제 이주. 「리아」 중단 발표. 연우는 *아무 장식 없는 보통 사람*이 된다. — 가장 낮은 곳에서, 가장 자유롭게.

### 3. 정서 곡선
결연 6 → (대면의 긴장) 5 → (카드를 찢는 해방) 8 → (추락의 상실) 4 → (자유의 묘한 평온) 6.

### 4. 씬 분해

#### scene 1 — 계약을 끝내다 (스튜디오 / 낮 / 연우·핸들러 오) *[F5 payoff 도입]*
- **씬 목적**: 연우가 「리아」 감정 원본 계약 파기를 *스스로* 선언. 객체→주체 전환의 행동.
- **진입 훅**: 면담 자리. 연우가 먼저 말한다 — "그만둘게요."
- **비트 전개**: 오의 경고 재확인(F7 추락·삭제) → 연우의 흔들림 없는 거부 → "내 감정은, 내 거예요" → 오의 *인간적인* 한 순간(적대자 아닌 압력, 그도 빌린 마음).
- **연출 지시**: 차가운 스튜디오에 떨어지는 결정의 무게. 오의 눈에 스치는 복잡함.
- **호흡·페이싱**: 대사 중심, 단단하게.
- **문체·보이스**: 연우=고요한 단호. 오=직업인의 마지막 배려.
- **대사 톤 샘플**: (오) "정말 다 잃을 거야." / (연우) "다 잃는 게 아니에요. 처음으로 갖는 거죠, 나를."
- **복선/캐논**: §9(계약·NDA 파기)·F7 / 핸들러=압력(악인 아님).

#### scene 2 — 금색을 찢다 (스카이레이어 / 낮 / 연우·강진우) *[F5 payoff]*
- **씬 목적**: 진우의 마지막 유혹을 거절하고 카드를 찢어 테마를 *행동*으로 완성.
- **진입 훅**: 진우가 마지막으로 카드를 내민다 — "이거면 다 없던 일이 돼."
- **비트 전개**: 안락·안전·기득권의 총합(F5) → 연우가 *그 자리에서 찢는다* → 진우의 집착이 무너진다(연민 어린 퇴장의 씨앗, 2권 재등장 여지).
- **연출 지시**: 찢기는 금색의 클로즈업. 진우의 표정 변화. 슬로우.
- **호흡·페이싱**: 행동의 정점에서 한 박자 정지.
- **문체·보이스**: 연우=해방. 진우=처음으로 통제를 잃음.
- **대사 톤 샘플**: (진우) "왜…… 다 줄 수 있는데." / (연우) "줄 수 없는 걸 원하니까요." (카드를 찢는다)
- **웹소설 장치**: 사이다 — 독자가 기다린 '기득권을 버리는' 카타르시스.
- **복선/캐논**: **F5 payoff**(기득권 vs 사랑) / §4 계급(특혜 박탈 트리거).

#### scene 3 — 추락, 그리고 (스카이레이어→그라운드레이어 / 며칠 / 연우 / 준서 짧은 교차) *[FL, ML 1컷]*
- **씬 목적**: 추락(강제 이주)의 대가와 「리아」 소멸을 보여주고, R16 재회의 무대를 깐다.
- **진입 훅**: 특혜 시스템이 일제히 꺼진다 — CQ 자동 보정 해제, 금빛 새장 회수.
- **비트 전개**: 연우의 그라운드레이어 강제 이주(보통 패시브로 추락) → 「리아」 프로젝트 중단 발표 → (ML 1컷) 준서가 리아 소멸 뉴스 앞에서 *상실감과 깨달음* 사이에 선다.
- **연출 지시**: 높은 곳에서 낮은 곳으로 내려가는 이주 동선. 꺼지는 「리아」 전광판.
- **호흡·페이싱**: 상실의 정적 → 자유의 옅은 빛으로.
- **문체·보이스**: 연우=홀가분함과 막막함의 공존. 준서=말없는 충격.
- **대사 톤 샘플**: (연우, 속으로) *이제 나를 지켜주는 건 아무것도 없다. 그래서 자유롭다.* / (준서) "리아가…… 사라졌다고?"
- **웹소설 장치**: 회말 훅 — 같은 도시, 가장 낮은 층에서 두 사람의 거리가 *처음으로 같아진다*(R16 견인).
- **복선/캐논**: §4·§8(추락 처분)·§9(특혜 박탈) / 「리아」 중단(F13 2권 연계).

### 5. 회말 훅 (클리프행어)
금색은 찢겼고, 「리아」는 사라졌고, 연우는 가장 낮은 곳에 섰다. 이제 두 사람 사이엔, 계급의 벽이 없다.

### 6. 금지 사항
- 진우를 완전 퇴장·악인 처단식으로 그리지 말 것(2권 재등장 여지, 연민 어린 결).
- 추락을 시스템 고발로 전면화 금지 — 연우의 *선택의 존엄*에 초점.
- 「리아」 소멸을 과잉 비극화 금지(R16 재정의를 위해 절제).

### 7. 사용 캐논 / 사용 금지 캐논
- 사용: §4·§8.4·§9(계약·특혜·추락)·§12 / F5·F7·F13(soft).
- 금지: 생명연장·빅터·봉인 편지.
