## ch06 비트 패킷: 아키텍트의 손길 · 거절할 수 없는 제안 [1막 전환점]

- **막 / 화수**: 1막 종결 / 1권 6화 (구 ch7 + ch8 + ch9 통합 ◎)
- **POV (시점·시제)**: 교차 — 한연우(FL) 주 → 이준서(ML) 코다 · 3인칭 제한 · 과거시제
- **분량 목표**: 7,000자 내외 (1막 전환점, 통합화)
- **로그라인**: 아키텍트 강진우가 '공식적 소유'를 제안하고, 연우 앞으로 거절할 수 없는 제안서가 도착한다 — 두 사람의 작은 평온에 처음으로, 시스템이 손을 뻗는다.

### 1. 챕터 목적 (드라마 기능)
- **강진우** 등장(라이벌·아키텍트)과 *계급의 벽*을 세운다(E3·E2 텍스처). F5(신분 보장 카드) seed.
- **1막 전환점(Act 1 turn)**: 파격 CQ 보상(V2)+거주권 위협이 담긴 제안서로 평온을 깨고, 준서가 *능동적으로 파헤치기로* 결심하게 한다.

### 2. 시작 상태 / 끝 상태
- **시작**: 준서와의 소박한 온기에 흔들리던 연우. 일상은 아직 평온.
- **끝**: 연우 앞으로 도착한 제안서 + 준서의 "뭔가 이상해, 알아내야겠어." → **1막 종결, 2막 추적 개시.**

### 3. 정서 곡선
설렘 6 → (진우 등장·화려함의 압박) 긴장 5 → (두 세계 사이 혼란) 4 → (제안서의 충격) 3 → (준서의 결심) 의지 6.

### 4. 씬 분해

#### scene 1 — 아키텍트의 손길 (스카이레이어 사교 자리 / 저녁 / 연우·강진우) *[FL]*
- **씬 목적**: 강진우 각인 + 계급의 벽 + F5 seed. 진우=악인 아닌 *'공식적 소유'의 유혹*.
- **진입 훅**: 금빛 새장 같은 만찬장. 진우가 연우에게 *공식 신분 상승·결혼*을 제안한다.
- **비트 전개**: 진우의 매끄러운 제안("내 옆이라면 추출 따위 안 해도 돼") → 도구적 사교계(E3)와 공부에 찌든 아키텍트 아이 한 컷(E2) → 진우가 건네는 *'비밀 신분 보장'*의 암시(F5 seed).
- **연출 지시**: 화려함의 *차가움*. 연우의 0.5초 늦은 웃음이 여기선 *가면*으로 복귀.
- **호흡·페이싱**: 우아하지만 숨 막히게.
- **문체·보이스**: 진우=세련·자기확신. 연우=속을 감춤.
- **대사 톤 샘플**: (진우) "넌 이런 데 어울려. 아래가 아니라." / (연우, 속으로) *어울린다는 게, 갇힌다는 뜻이라면.*
- **복선/캐논**: **F5 seed**(신분 보장 카드)·E3·E2 / §4 계급·§9 금빛 새장.

#### scene 2 — 두 개의 세계 (스카이레이어 ↔ 서브레이어 / 같은 밤 / 연우) *[FL]*
- **씬 목적**: 진우(화려함) vs 준서(진심) 사이 연우의 균열을 *대비 몽타주*로.
- **진입 훅**: 만찬을 빠져나온 연우가 충동적으로 서브레이어로 내려간다.
- **비트 전개**: 화려한 위층의 기억 ↔ 준서와의 투박한 커피 한 잔의 온기 → "어느 쪽이 진짜 나지?" → 답을 미룬 채 돌아선다.
- **연출 지시**: 고도(高度)의 대비를 시각으로(300m ↔ 지하). 같은 밤, 두 세계.
- **호흡·페이싱**: 짧은 교차 컷.
- **문체·보이스**: 연우의 내적 갈등(안정 vs 설렘).
- **대사 톤 샘플**: (속으로) *위에선 숨이 막히고, 아래에선 들킬까 무섭다.*
- **복선/캐논**: §12.1 연우 NEED(한 시간만 진짜 자신으로).

#### scene 3 — 거절할 수 없는 제안 (연우의 거처 / 새벽 / 연우→준서) *[FL→ML 전환]*
- **씬 목적**: **1막 전환점.** V2(파격 CQ 보상)+거주권 위협 제안서로 평온을 깨고, ML로 넘겨 준서의 능동 결심을 점화.
- **진입 훅**: 새벽, 연우 앞으로 봉인 제안서가 도착한다 — *"정서 데이터 협조 확대 시, 해외여행·시간의 자유(V2). 거절 시 현 거주 안전 보장 불가."*
- **비트 전개**: (FL) 연우의 공포 — 자유라는 미끼와 추락이라는 협박 사이 → (ML 코다) 며칠째 연우의 연락이 끊기고 어딘가 *어긋난* 기운을 느낀 준서가 "뭔가 이상해. 그 사람, 알아내야겠어."
- **연출 지시**: 제안서의 차가운 활자. 장면 끝에 *처음으로 능동적인* 준서의 얼굴.
- **호흡·페이싱**: 충격에서 의지로 전환. 단문 연쇄.
- **문체·보이스**: 연우=떨림, 준서=조용한 결단(체제 비판이 아니라 *사람*에 대한 관심).
- **대사 톤 샘플**: (연우, 속으로) *자유를 미끼로 건 협박.* / (준서) "왜 자꾸 사라지는 거야, 당신은."
- **웹소설 장치**: 회말 클리프행어 — 1막의 평온이 깨지고, 2막의 추적이 시작된다.
- **복선/캐논**: **V2 plant**·F5 연계 / §3.2·§8(CQ)·§9(특혜 박탈 위협).

### 5. 회말 훅 (클리프행어)
자유를 미끼로 건 협박장. 그리고 처음으로, 준서가 *먼저* 움직이기로 한다. — 평온은 끝났다.

### 6. 금지 사항
- 제안서 배후(생명연장·컨소시엄·빅터) 노출 금지(2·3권). V2는 'CQ 보상' 표면만.
- 진우를 단순 악역으로 평면화 금지('공식적 소유'의 유혹).
- 준서의 결심을 *체제 전복 의지*로 그리지 말 것 — 어디까지나 '연우'라는 사람을 향한 것.
