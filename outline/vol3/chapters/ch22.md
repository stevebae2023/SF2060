## ch22 비트 패킷: 파국 (2막 종결)

- **막 / 화수**: 2막 / 3권 22화 (**2막 종결 — 파국**)
- **POV (시점·시제)**: 이준서(ML)→한연우(FL) 더블 POV · 3인칭 제한 · 과거시제
- **분량 목표**: 7,500자 내외 (2막 종결, 상한 가까이)
- **로그라인**: 러다이트의 총공격과 빅터 권의 방어벽이 충돌한다. 실험실이 폭발 위기에 처하고, 통제를 잃은 연우의 정서 데이터가 전 세계로 무차별 살포되며 2막이 파국으로 닫힌다.

> ⚑ **2막 종결 — 점입가경의 최대 폭발.** 빅터(유지)·러다이트(파괴)·시스템(보정)의 세 힘이 한 점에서 충돌. **D1 엄수**: 데이터 살포는 'AGI 폭주/각성'이 아니라 *물리적 충돌로 시설 통제가 깨진 결과*. 시스템은 붕괴가 아니라 보정 한계를 드러낼 뿐.

### 1. 챕터 목적 (드라마 기능)
- **2막 종결 파국**: 세 세력의 충돌로 연우의 데이터가 전 세계로 살포되는 통제 불능 사태 — 3막(견딤) 진입의 결정적 사건.
- 빅터의 '완벽한 통제'가 외부 변수(러다이트)에 의해 처음 깨짐을 보여줘 점입가경의 임계를 터뜨림.
- 살포된 데이터가 ch23(전 시민 공명)의 직접 원인이 되도록 셋업.

### 2. 시작 상태 / 끝 상태
- **시작**: 준서가 협공 작전 중 러다이트·시스템 방어선의 충돌 한복판에 뛰어든다(ch21 회말).
- **끝**: 실험실이 충돌로 파괴되며 연우의 정서 데이터가 통제를 잃고 전 시민의 넥패치로 무차별 살포된다. 연우는 접속에서 풀려나지만 의식이 도시 전역에 흩어진 위기. 빅터는 통제력을 처음 상실. 준서는 폐허 속에서 연우를 찾는다.

### 3. 정서 곡선 (감정 온도·텐션)
충돌 8 → (실험실 파괴) 9 → (데이터 살포 폭발) 10(피크) → (연우 분산·혼돈) 8 → (준서의 절박한 수색) 7.

### 4. 씬 분해

#### scene 1 — 세 개의 불길 (빅터 시설 외곽·내부 / 밤 / 준서·서강림·시스템 방어대)
- **장소/시간/등장인물**: 빅터 시설의 외곽과 침투로, 밤 / 준서 · 서강림과 러다이트 · 시스템 방어대.
- **씬 목적**: 빅터·러다이트·시스템 세 힘의 물리적 충돌을 대규모 액션으로.
- **진입 훅**: 서강림의 망치가 시설 방어막을 내리친다. "오늘, 이 발전기를 끈다!"
- **비트 전개**: 러다이트 총공격 ↔ 시스템 방어대 응전 → 준서가 그 틈으로 침투 → 서강림과 준서의 짧은 교차("넌 지키러, 난 부수러 — 길은 같군") → 충돌이 시설 핵심부로 번짐.
- **연출 지시**: 카메라=준서의 침투 동선. 폭음·화광·무너지는 구조물. 러다이트의 원시적 파괴 vs 시스템의 차가운 방어.
- **호흡·페이싱**: 단문 연발의 카오스, 준서·서강림 교차에서 한 박자.
- **문체·보이스**: 준서=목표 외길. 서강림=파괴의 쾌감과 허무 동시.
- **대사 톤 샘플**: (서강림) "지킬 게 있다고? 부수고 나면 다 똑같아진다." (준서) "아뇨. 저는 한 사람만 지키면 돼요."
- **웹소설 장치**: 씬말 훅 — 충돌의 충격으로 시설 핵심부의 봉인이 균열.
- **복선/캐논**: 캐논 §3(러다이트 파괴)·§2(빅터 시설) · 서강림 아크 · 러다이트≠언플러그드(분리 유지) · D1.

#### scene 2 — 흩어지는 마음 (실험실 핵심부 / 같은 밤 / 연우·빅터·핸들러 오)
- **장소/시간/등장인물**: 파괴되는 실험실 핵심부, 같은 밤 / 연우 · 빅터 · 핸들러 오.
- **씬 목적**: 통제 상실로 연우의 데이터가 전 세계로 살포되는 파국의 심장.
- **진입 훅**: 충돌의 진동으로 접속 장치가 폭주한다. 빅터가 처음으로 외친다. "통제를 유지해! 그녀는 마지막 노드다!"
- **비트 전개**: 시설 파괴로 연우의 데이터가 봉인을 벗어남 → 전 시민 넥패치로 무차별 살포 시작 → 연우의 접속이 강제 해제되며 의식이 도시 전역에 흩어지는 위기 → 핸들러 오가 마지막 순간 연우의 의식 닻(준서 기억)을 보호하는 선택(F26 완결).
- **연출 지시**: 빅터의 첫 통제 상실(차가움이 깨지는 한 컷). 살포는 빛의 범람으로. 1인칭 AGI 금지.
- **호흡·페이싱**: 폭발의 가속, 살포의 순간 흰 정적.
- **문체·보이스**: 연우=분산의 공포 속 닻 사수. 빅터=처음 흔들림. 오=인간적 선택.
- **대사 톤 샘플**: (오, 작게) "…미안합니다. 이건 아니었어요." / (연우, 흩어지며) '준서… 박자… 잊지 마.'
- **웹소설 장치**: 씬말 떡밥 — 살포된 데이터가 도시의 모든 넥패치에서 '낯선 진짜 아픔'으로 깨어난다(ch23 직결).
- **복선/캐논**: 캐논 §2(살포) · F26 완결(오의 전환) · ch23 공명 직결 · D1(통제 상실≠각성).

#### scene 3 — 폐허에서 부르다 (무너진 실험실 / 새벽 / 준서·연우)
- **장소/시간/등장인물**: 폭발이 잦아든 실험실 잔해, 새벽 / 준서 · (분산된) 연우.
- **씬 목적**: 2막을 파국으로 닫되, 준서가 연우의 흩어진 의식의 닻을 붙잡는 한 가닥 희망.
- **진입 훅**: 준서가 잔해를 헤치며 연우를 부른다. 대답 대신, 사방의 부서진 단말에서 연우의 목소리 조각들이 흩어져 들린다.
- **비트 전개**: 연우의 육체는 풀려났으나 의식은 도시에 분산 → 준서가 비디지털 박자를 두드려 닻을 부름 → 가느다란 응답 → 그러나 데이터 폭풍이 이미 도시를 덮침.
- **연출 지시**: 폐허의 잿빛, 흩어진 목소리. 준서의 두드림만이 일정한 박자.
- **호흡·페이싱**: 절망과 희망의 교차, 마지막에 박자 하나가 또렷.
- **문체·보이스**: 준서의 포기 없는 부름.
- **웹소설 장치**: 회말 직전 — 도시 전역의 사람들이 동시에 가슴을 움켜쥔다(공명 시작).
- **복선/캐논**: ch23 데이터 폭풍 직결 · 비디지털 닻(F32 라인) · 테마.

### 5. 회말 훅 (클리프행어)
새벽, 네오 서울 전역의 수백만 넥패치가 동시에 떨린다. 사람들이 난생처음 '타인의 진짜 아픔'을 느끼고 거리로 쏟아져 나온다. 준서가 폐허 속에서 흩어진 연우를 향해 박자를 두드린다. "흩어지지 마. 내가 다 모을게." — 2막 종료.

### 6. 금지 사항
- 데이터 살포를 'AGI 폭주·각성·붕괴'로 묘사 금지(D1 — 물리 충돌에 의한 시설 통제 상실).
- 시스템 전복 금지(시스템은 보정 한계를 드러낼 뿐, 무너지지 않음).
- 연우의 '죽음/완전 소멸' 확정 금지(분산 위기까지 — ch23~27에서 수습).
- 러다이트-언플러그드 동질화 금지.

### 7. 사용 캐논 / 사용 금지 캐논

- 금지: AGI 각성·붕괴·전복 · 연우 소멸 확정 · 저항세력 융합.
