## A. 웹소설 형식 규격 (전 챕터 공통)

- **분량**: 회당 **6,000–8,000자** (PREMISE v3.1 / REWRITE_BRIEF_v2 기준).
- **문단**: 1–3문장 단문단. 잦은 행갈이로 모바일 가독성 확보. 긴 설명 덩어리 금지.
- **첫 문장 훅**: 매 회 도입 1–2문장 안에 궁금증·장면·감각 중 하나로 즉시 끌어들인다(상황 설명 X).
- **리듬**: 대사·행동 중심. 묘사는 짧고 감각적으로. 정보는 장면에 녹여 보여주기(showing).
- **끊어치기**: 긴장·반전 직전 짧은 문장/한 줄 문단으로 호흡을 끊는다.
- **회말 훅**: 매 회 끝에 떡밥·반전·미해결 질문(클리프행어)으로 다음 화를 견인.
- **사이다/고구마 배분**: 답답함(고구마)이 쌓이면 작은 해소(사이다)를 배치해 이탈 방지. 2권은 긴장↑이므로 준서·지호 케미의 가벼운 사이다를 호흡 조절용으로 활용.
- **톤**: 1권 계승 — 경쾌·발랄 + 따뜻한 로맨스(밝은 준서). 2권은 그 위에 **스릴러 긴장**을 한 겹. 디스토피아는 전면화 없이 배경의 결로.

## B. 비트 패킷 표준 양식 (chXX.md는 아래 순서를 따른다)

```
## chXX 비트 패킷: <제목>

- 막 / 화수 / POV(시점·시제) / 분량 목표
- 한 줄 로그라인 (이 화의 핵심 사건·감정)

### 1. 챕터 목적 (드라마 기능)
왜 이 화가 존재하는가 — 플롯 전진 + 정서 변화 + 복선 처리.

### 2. 시작 상태 / 끝 상태
독자·인물이 화 시작과 끝에 각각 어디에 있는가(정보·감정·관계).

### 3. 정서 곡선 (감정 온도·텐션)
시작 온도 → 비트별 상승/하강 → 끝 온도. 어디서 끊고 어디서 터뜨리는지.

### 4. 씬 분해 (scene 1..n) — 각 씬마다:
- **장소/시간/등장인물**
- **씬 목적** (이 씬이 없으면 안 되는 이유)
- **진입 훅** (첫 1–2문장 연출 — 무엇으로 끌어들이나)
- **비트 전개** (일어나는 일의 순서, action beats)
- **연출 지시 (mise-en-scène)**: 카메라/시선(누구의 눈), 공간·소품·빛·소리, 감각 디테일, 상징·모티프, 정보 공개 타이밍.
- **호흡·페이싱**: 문장 길이 운용(장문→단문 전환점), 여백/행갈이, 가속·감속 지점, 침묵의 사용.
- **문체·보이스**: 해당 POV의 어조(준서=밝고 단순·구체/연우=섬세·경계·이중감정), 유머·서정·긴장 배합 비율.
- **대사 톤 가이드** + 샘플 1–2줄 (확정 대사 아님, 결·온도 예시).
- **웹소설 장치**: 씬말 미니 훅·떡밥·반전.
- **복선**: plant/payoff 코드(F-번호) + 사용 캐논 §참조.

### 5. 회말 훅 (클리프행어)
다음 화를 견인하는 마지막 한 컷/한 줄.

### 6. 금지 사항
이 화에서 드러나면 안 되는 것(스포일러·하드룰·시점 누설).

### 7. 사용 캐논 / 사용 금지 캐논
근거 §, 그리고 아직 열면 안 되는 비밀.

### 8. 연속성 체크
직전 화와의 연결, 인물 위치·시간 경과, 복선 상태 갱신.
```
