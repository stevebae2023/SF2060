## 시점 운용 원칙
1. **균형**: 연우(비밀 보유자)와 준서(비밀 추적자)의 시점을 교차시켜 독자가 두 사람의 정보 격차를 즐기게 한다.
2. **반전 타이밍**: 1막 후반(ch7-8)에는 연우의 내적 갈등을 깊게 파고, 전환점(ch9)부터는 준서의 외부적 추적에 힘을 싣는다.
3. **정보 제한**: 준서 POV일 때는 연우의 구체적인 세션 내용이나 진우와의 밀약을 철저히 준서의 시각(의심)으로만 필터링한다.
4. **Sub-POV 활용**: B-플롯(E2)이나 세계관 확장이 필요할 때 조연의 시점을 1~2회 삽입하여 메인 플롯의 긴장을 잠시 환기한다.

## 2권 시점 운용 원칙
1. **1권 패턴 계승**: ML(준서)↔FL(연우) 교차로 정보 격차의 아이러니 유지. 2권 균형은 ML 12 / FL 11 / 교차 4 / Sub 주도 2 / 인터루드 2로 대체로 대칭.
2. **인터루드 절제**: 관찰 인터루드(ch17·25)는 V4 텍스처 전용. 1인칭 AGI 각성 절대 금지, 분량 짧게(메인 긴장 환기).
3. **FL 주체화**: 1권의 '침묵하는 연우'에서 2권은 ch21 '먼저 말하는 연우'로. FL POV를 갈등 결정 지점(ch13·21·23·27)에 배치해 성장 아크를 시점으로 뒷받침.
4. **Sub-POV(지호·강민재)**: 탐문·세대 시선 환기에 한정(ch6·12·20), 메인 추진력 분산 방지.
