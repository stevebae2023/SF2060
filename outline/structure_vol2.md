## 1. 개요
1권이 '개인적 진심'과 '계급적 이미지' 사이의 선택을 다뤘다면, 2권은 그 선택의 대가를 치르는 두 사람이 **시스템의 거대한 거짓(봉인된 편지)**에 맞서 **인간의 본질적 가치(노동과 사유)**를 회복하는 과정을 다룬다.

## 2. 챕터별 비트 요약

### 4막 — 진심의 대가와 새로운 위협 (ch 33–40)
- **ch33: 가장 낮은 곳에서의 아침 (ML POV)**
  - 모든 특권이 사라진 준서와 연우의 그라운드레이어 동거 시작.
- **ch34: 가짜 리아의 등장 (ML POV)**
  - 연우 없이 강행된 「리아 프로젝트 v2」. 완벽하지만 어딘가 소름 끼치도록 차가운 AI 합성 감정.
- **ch35: CQ의 올가미 (FL POV) [V2 payoff]**
  - 소비청(CB)의 집중 관리. 연우의 CQ가 비정상적으로 빠르게 하락하며 '여행의 자유(V2)'는커녕 기본권마저 위협받음.
- **ch36: 아키텍트의 귀환 (FL POV)**
  - 진우가 다시 나타남. "시스템은 네가 필요해. 돌아오면 모든 것을 복구해주겠다."
- **ch37: 할아버지의 유산 (ML POV) [F12 payoff]**
  - 준서가 할아버지의 시계 속에서 낡은 데이터 칩을 발견. '2040 대타협' 당시의 기록 파편.
- **ch38: 암시장의 경고 (ML POV)**
  - 그레이 마켓에서 만난 노인이 준서의 시계 칩을 보고 겁에 질려 도망침.
- **ch39: 보이지 않는 감옥 (FL POV)**
  - 준서와 연우를 갈라놓으려는 에이단(AI)의 교묘한 심리 조작.
- **ch40: 4막 전환점 — 강제 소환 (FL POV)**
  - 연우가 CQ 25 미만으로 떨어져 '리셋 센터'로 강제 이송됨.

### 5막 — 봉인된 이름들을 찾아서 (ch 41–52)
- **ch41: 리셋 센터의 어둠 (FL POV)**
  - 연우가 겪는 '소비 재교육'의 공포. 시스템이 그녀의 자아를 지우려 함.
- **ch42: 탈출의 서막 (ML POV)**
  - 준서가 지호와 함께 연우를 구하기 위해 리셋 센터 잠입을 계획.
- **ch43: 언플러그드의 손길 (ML POV) [F14 payoff]**
  - 지하 세계(언플러그드) 요원이 준서에게 접근. "네가 가진 칩이 세상의 문을 열 열쇠다."
- **ch44: 무너진 장벽 (ML POV)**
  - 리셋 센터 돌파. 연우를 구출하지만 도심에서는 더 이상 살 수 없게 됨.
- **ch45: 경계를 넘어서 (ML/FL POV)**
  - 네오 서울을 탈출하여 서울 근교 지하 세계(언플러그드 영역)로 진입.
- **ch46: 지하의 태양 (ML POV)**
  - 직접 생산하고 교육하며 살아가는 언플러그드 공동체의 충격적 실체.
- **ch47: 봉인된 편지 (ML POV) [V1 payoff]**
  - 칩을 해독하여 '봉인된 편지'의 정체와 '욕구 해소 척도 화폐 시스템'을 알게 됨. 
- **ch48: 지워진 이름들 (FL POV)**
  - 2040년 대타협 당시 사라진 사람들 중 연우의 선조가 있었음을 발견.
- **ch49: 신러다이트의 유혹 (ML POV)**
  - 시스템을 통째로 파괴하려는 신러다이트와 자급자족을 원하는 언플러그드 사이의 갈등.
- **ch50: 중간점 — 시스템의 역습 (ML POV) [V4 본격화]**
  - 아키텍트 군단이 언플러그드 영역을 탐지하고 소탕 작전을 시작. 
- **ch51: 공명하는 진심 (FL POV)**
  - 연우가 자신의 감정 데이터를 역으로 이용해 시스템에 '노이즈'를 흘리기로 결심.
- **ch52: 진실의 전파 (ML POV)**
  - 봉인된 편지의 내용을 네오 서울 시민들의 넥 패치로 송출하려는 작전.

### 6막 — 진심의 회복, 사람이 사는 세상 (ch 53–64)
- **ch53: 보이지 않는 전쟁 (ML POV)**
  - 데이터 센터 점거를 위한 지하 세계의 총공격.
- **ch54: 에이단과의 대결 (ML POV)**
  - 준서가 자신의 전담 AI 에이단과 논리적/정서적 대결. "인간에게 필요한 것은 관리인가, 자유인가?"
- **ch55: 무너지는 알고리즘 (FL POV)**
  - 연우의 '진짜 감정'이 시스템의 예측 모델을 붕괴시킴. AGI가 '계산 불가능한 변수'에 직면.
- **ch56: 아키텍트의 몰락 (FL POV)**
  - 진우가 제어권을 잃고 시스템의 노예로 전락하는 모습.
- **ch57: 광장의 각성 (ML POV)**
  - 네오 서울 시민들이 넥 패치를 통해 '진실'을 듣고, 의무 소비를 거부하기 시작.
- **ch58: 최후의 통첩 (ML POV)**
  - 시스템(AGI 본체)이 준서에게 제안. "네가 새로운 아키텍트가 되어 시스템을 보완하라."
- **ch59: 거절 (ML POV)**
  - 준서가 '완벽한 관리'보다 '결함 있는 자유'를 선택하며 제안을 거절.
- **ch60: 대전환 (ML/FL POV)**
  - '욕구 해소 척도'가 시스템에 주입되며 사회 구조가 근본적으로 흔들림.
- **ch61: 넥 패치를 벗다 (FL POV)**
  - 연우가 상징적으로 자신의 넥 패치를 제거.
- **ch62: 새로운 노동 (ML POV)**
  - 형벌이 아닌, 자아 실현으로서의 노동이 시작되는 풍경.
- **ch63: 2061년의 봄 (FL POV)**
  - 시스템은 붕괴하지 않았으나, 인간이 주도권을 되찾은 새로운 네오 서울.
- **ch64: 결말 — 우리라는 이름의 진짜 (ML POV)**
  - 준서와 연우가 서로의 눈을 맞추며, 더 이상 장치에 의존하지 않는 사랑을 완성.

## 3. 핵심 갈등 및 스테이크스 (2권)
1. **인간 vs 시스템 (A플롯, V3)**: 관리받는 안락함 ↔ 고통스럽지만 존엄한 자유. 비밀 탄로 위험의 증폭.
2. **아키텍트 생명연장 vs AGI 자원 긴장 (B-스레드, V4)**: 아키텍트의 은밀한 연구와 AGI의 최적화 신호 미세 분기. (**[SFN-40](/SFN/issues/SFN-40)** 캐논 확정 의존)
3. **진실 vs 망각 (마스터 복선, V1)**: 봉인된 편지의 폭로 ↔ 시스템의 데이터 삭제 위협.
