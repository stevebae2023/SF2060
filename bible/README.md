# bible/ — 세계관 바이블

**소유: [02 세계관 설계자](../docs/AGENTS_02.md)**

본 폴더는 작품 세계의 캐논을 담는다. 모든 에이전트가 읽기 가능.
02 외의 에이전트가 변경이 필요하면 02에 이슈로 요청.

## 권장 파일 (예시 — 작품에 맞춰 추가/조정)
- `physics.md` — 물리/기술 규칙 (FTL 여부, 통신 지연, 에너지 등)
- `society.md` — 사회·정치·경제 체계
- `timeline.md` — 작품 내 연표 (큰 사건 위주)
- `factions.md` — 등장 세력·조직
- `tech.md` — 등장 기술의 작동 원리·한계
- `geography.md` — 무대 지리·환경

각 항목에는 "규칙"과 "그 규칙이 만드는 결과"를 함께 적는다.
설정 상태: `확정` / `잠정` / `검토중` 태그를 사용한다.
